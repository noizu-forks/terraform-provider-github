# Project Layout

Fork tree: `noizu-forks/terraform-provider-github` (upstream `integrations/terraform-provider-github`, base release tag `v6.13.0`). Branch `develop` carries the Noizu line; `main` is a pristine upstream mirror.

Counts below are from `git ls-files` at the doc-sweep commit — this tree only, not upstream at large.


## Key files requiring setup

| File | Action |
|------|--------|
| `~/.config/opentofu/github-fork.tfrc` | Written by `scripts/noizu/build-dev-override.sh`; use only via `TF_CLI_CONFIG_FILE` |
| `.golangci.new.yml` | Generated by `make lintcheck-strict`; gitignored |
| `GITHUB_TOKEN` / `app_auth` | Provider credentials — see [PROJ-SCHEMA.md](PROJ-SCHEMA.md) config section |
| `.github/workflows/*` | Present but **disabled on the fork** (NOIZU.md rule 6); do not enable |

## Not in this tree

- No relational database, migrations, container image or deploy manifests — the build artifact is a single Go plugin binary.
- No Noizu resources yet: `noizuResources` / `noizuDataSources` are empty maps (scaffold only, 2026-10-14).
